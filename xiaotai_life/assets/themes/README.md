# Theme Assets

Theme images are grouped as visual packs instead of single reusable posters.
Each branded theme provides separate images for preview, login, splash, and
in-app scene cards so the UI changes as a complete theme.

The default light theme also includes `default/background.png`, used as the
global backdrop image for the default visual pack.

## Sources

- `shinchan/*`: official Crayon Shin-chan portal images from
  `https://www.shinchan-app.jp/`.
- `jay/*`: official JVR Music images from `https://www.jvrmusic.com/`.
- `eggy/*`: official Eggy Party / NetEase promotional images from
  `https://www.eggyparty.com/` and NetEase image CDN URLs referenced by that
  page.

For public distribution, confirm the final product's brand/image licensing
before shipping.

# 备忘 / 记心情 UI 接口与字段预留记录

## 已完成 UI

- 列表页：顶部标题、搜索 / 列表管理入口、全部 / 备忘 / 心情 / 置顶分段、按更新时间排序提示、总数、置顶卡片、普通备忘卡片、浮动新增按钮、底部导航样式。
- 新建备忘 / 心情页：备忘 / 心情分段、标题输入、内容输入、心情选择、标签选择、提醒入口、日期入口、图片入口、存为草稿、保存。
- 编辑页：复用编辑表单，支持保存、删除入口、图片占位显示。
- 删除确认：暗色遮罩、吉祥物、确认文案、取消 / 删除按钮。
- 心情卡片页：顶部返回 / 筛选入口、心情筛选条、双列心情卡片、浮动新增按钮、底部吉祥物。
- 本地搜索 / 心情筛选：列表搜索支持标题、内容和标签；心情卡片筛选条支持按心情过滤。
- 日期 / 标签：日期选择会写入备忘更新时间；心情和标签以内容标记形式持久化并在展示时隐藏标记。

## 字段与接口预留

- `mood`: 当前以 `[mood:开心]` 内容标记持久化并回填 UI，后续建议在 `AppMemo` 中增加正式字段。
- `tags`: 当前以 `[tags:学习,阅读]` 内容标记持久化并回填 UI，后续建议在 `AppMemo` 中增加正式数组字段。
- `remindAt`: 设置提醒入口已预留，后续需要接入本地通知或提醒服务。
- `memoDate`: 日期选择已接入当前备忘的更新时间；后续建议增加独立备忘日期字段。
- `imagePaths`: 图片入口已预留，当前用本地占位图展示，未保存图片路径。
- `draft`: 存为草稿按钮已通过 `[draft]` 内容标记保存，后续建议增加草稿状态字段。
- `memoType`: 备忘 / 心情分段已预留，当前不区分落库类型。
- `searchMemos`: 已接入本地搜索。
- `moodFilter`: 已接入本地心情筛选。
- `sortMode`: 按更新时间排序提示已展示，后续可接入排序切换。

# 小笨漫画 UI 重构接口预留记录

## 已接入能力

- 漫画列表：继续使用 `DailyComicService.instance.fetchPublished(pageSize: 30)` 拉取已发布漫画。
- 漫画图片：继续使用 `DailyComicService.instance.resolveAssetUrl(imageUrl)` 解析后端图片地址。
- 列表刷新：支持下拉刷新和错误状态重试。
- 最新 / 往期：界面已按参考图拆分为两个入口，往期当前基于已拉取列表过滤展示。
- 漫画搜索：顶部搜索按钮已接入本地关键字筛选，支持按标题和发布日期过滤当前已拉取列表。
- 阅读页：支持横向分页阅读、上一页 / 下一页按钮、图片缩放查看。
- 末页状态：最后一页后显示“已经是最后一话啦”和“去看往期”按钮。
- 返回路由：阅读页返回列表，列表页返回上级或百宝箱。

## 预留接口

- 服务端搜索：当前搜索仅过滤已拉取列表，后续大数据量时可接入漫画标题/话数搜索 API。
- 漫画分享：阅读页右上角分享按钮已保留入口，待接入分享图片或链接能力。
- 往期分页：当前仅使用已拉取的 30 条数据，待接入 `page/pageSize` 分页加载更多。
- 话数编号：当后端标题不含“第 N 话”时使用 UI 占位编号，建议后端补充 `episodeNo` 字段。
- 已读状态：可接入本地 `seenDailyComicIds` 或新增漫画阅读进度表。
- 更新提醒图标：列表第三项的提醒图标为参考 UI 占位，待接入单话提醒/订阅状态。
- 梦想翻页：当前使用横向 `PageView`，后续可接入自定义翻页动画。
- 服务通知后拉取：启动通知逻辑已在应用层存在，漫画页本身预留刷新和列表展示入口。

## 已修复问题

- 顶部标题安全区：列表页标题、搜索按钮，以及阅读页标题、返回 / 分享按钮已限制在各自区域内，长标题会省略，避免按钮和标题重合。

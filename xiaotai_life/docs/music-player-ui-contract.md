# 音乐播放器 UI 接口与字段预留记录

## 已完成 UI

- 播放详情页：顶部返回 / 更多入口、专辑封面卡片、歌曲名、歌手、当前歌词、播放进度、上一首 / 播放暂停 / 下一首 / 循环播放。
- 播放列表页：顶部返回 / 更多入口、播放列表标题、相册 / 歌词分段入口、搜索 / 新增入口、当前播放歌曲高亮、歌曲封面、歌名、歌手、时长。
- 现有播放能力保留：继续使用 `MusicService.fetchTracks()` 拉取音乐列表，使用 `just_audio` 处理播放、暂停、进度拖动、上一首、下一首和单曲循环。
- 歌词同步：已解析 LRC 时间标签，并根据真实音频播放进度切换当前歌词行；无歌词时展示中性空态。
- 音乐时长：前端已读取后端 `durationSeconds` 字段；后端未提供且播放器未返回真实时长时显示 `00:00`。
- 全屏播放器：音乐页进入后隐藏主底部导航，避免底部控制区被遮挡。
- 空数据 / 接口失败占位：接口暂无数据时展示空曲库状态，不展示 UI 样例曲目。

## 字段与接口预留

- `likeCount`: 收藏数未接入前不展示固定占位。
- `likedByMe`: 红心状态当前为页面本地状态，默认未收藏；后续接入用户收藏接口。
- `playlistMode`: 顶部相册 / 歌词分段入口已预留，当前不切换数据源。
- `searchTracks`: 播放列表搜索入口已预留。
- `addTrackToPlaylist`: 新增歌曲入口已预留。
- `downloadTrack`: 下载入口已预留。
- `trackMoreMenu`: 更多菜单入口已预留。
- `coverUrl`: 只有后端返回封面时展示真实封面；无封面时展示中性图标底板。
- `lyrics`: 已支持 LRC 格式字符串；后续建议接口统一返回带时间标签的歌词。

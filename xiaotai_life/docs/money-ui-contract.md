# 记账 UI 接口与字段预留记录

## 已完成 UI

- 账单列表：月份标题、收入 / 支出 / 结余概览、按日期分组账单、顶部新增按钮、悬浮新增按钮、筛选入口、月度总结入口。
- 新增 / 编辑记账：收入 / 支出切换、金额输入、分类九宫格、备注、日期、支付方式、确认 / 取消按钮。
- 删除记账：编辑账单时展示删除入口，并在删除前弹出确认弹窗。
- 支付方式：现金 / 微信 / 支付宝 / 银行卡已保存到 `AppMoneyRecord.paymentMethod`，筛选页支付方式条件已参与过滤。
- 日期与时间：月份选择、记账时间选择、日历日期选择均已可用。
- 分类筛选：筛选页分类入口已接入底部选择弹窗，并参与列表过滤。
- 选择页：分类选择、备注输入、常用备注、日期日历、时间入口。
- 月度总结：收入 / 支出 / 结余统计、趋势图、支出分类占比、每日平均。
- 筛选条件：时间范围、交易类型、支付方式、金额范围、分类、应用筛选。

## 字段与接口预留

- `categoryIconAsset`: 当前使用 Material Icons 作为分类图标，后续可接 iconfont 或本地图片资源。
- `customDateRange`: 筛选页自定义时间范围已展示，当前仍按本月逻辑回退，后续可接起止日期选择。
- `summaryTrendSeries`: 月度趋势图当前由本地真实记录聚合；后续可接每日收入 / 支出聚合接口。
- `categoryShareSeries`: 分类占比已按当前记录做基础统计，后续可接服务端统计接口。

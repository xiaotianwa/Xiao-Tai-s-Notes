# 纪念日 UI 接口与字段预留记录

## 已完成 UI

- 纪念日列表：全部 / 即将到来 / 已过去分段、倒数卡片、添加入口、搜索入口、管理入口。
- 添加 / 编辑纪念日：名称、日期、倒数/正数类型、分类、颜色、图片、备注输入区。
- 纪念日详情：主图、倒数/正数天数、目标日、时间进度、基础信息、分享/删除操作。
- 分类卡片视图：爱情、生日、生活、旅行、学习、其他。
- 本地搜索 / 分类筛选：搜索入口支持按名称过滤；分类卡片点击后返回列表并按分类过滤，列表顶部支持清除筛选。
- 管理视图：批量选择、删除确认、拖拽排序入口。

## 字段预留

- `note`: 备注输入区目前仅做 UI 预留，`AppAnniversary` 模型暂无备注字段。
- `repeatRule`: 详情页目前固定显示每年重复，模型暂无重复规则字段。
- `sortIndex`: 管理页拖拽排序入口已预留，模型暂无排序字段。
- `sharePayload`: 分享按钮已预留，后续可接入海报生成或系统分享。
- `searchQuery`: 已接入本地名称筛选，后续如需要跨端同步搜索历史可扩展字段。
- `categoryFilter`: 已接入本地分类筛选，当前不额外保存筛选状态。

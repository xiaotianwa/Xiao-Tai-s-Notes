# 提醒 UI 重构接口预留记录

## 已接入能力

- 提醒列表：保留全部 / 进行中 / 已完成三个筛选入口，空数据时使用参考 UI 样式的本地占位数据。
- 新建 / 编辑提醒：继续使用 `AppLocalStore.upsertReminder` 保存标题、日期时间、重复规则、提前通知、状态栏提醒、优先级和图标。
- 提醒详情：支持从列表进入详情页，并提供编辑、标记完成和延迟 15 分钟入口。
- 完成状态：继续使用 `doneDateKey` 和 `completed` 判断当天完成状态。
- 本地通知：继续调用 `LocalNotificationService.scheduleReminder`、`cancelReminder`、`syncPinnedReminders`。
- 逾期确认：保留逾期弹窗，可标记完成、延迟 15 分钟或忽略本次。
- 删除确认：长按列表项会弹出删除确认弹窗，避免误删。

## 预留接口

- 系统锁屏通知样式：参考图中的锁屏界面属于系统通知展示，当前仅保留通知调度入口，实际样式由 Android 系统控制。
- 备注字段：UI 已提供备注输入和详情占位，但当前 `AppReminder` 模型没有 `note` 字段，待后端和本地模型补字段后落库。
- 图标选择器：当前使用默认图标和已有 icon 字段映射，待接入 iconfont 或本地资源选择器。
- 自定义重复规则：当前支持不重复 / 每天 / 每周 / 每月，待接入更多重复配置。
- 提醒搜索：顶部功能按钮预留入口，待接入搜索或筛选面板。
- 通知栏提醒管理：状态栏提醒开关已接入 `pinned`，更多通知策略待设置页统一接入。
- 已完成分组接口：当前按本地时间分组为今天 / 昨天 / 更早，待后端提供完成时间字段后可精确分组。

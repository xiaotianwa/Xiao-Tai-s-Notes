# 情侣 100 件事 UI 接口与字段预留记录

## 已完成 UI

- 默认清单页：顶部情侣吉祥物氛围区、全部 / 进行中 / 已完成统计、事项列表、浮动新增按钮、底部清单 / 照片墙 / 已完成入口。
- 事项详情页：返回 / 分享入口、事项状态卡、分类 / 进度 / 创建时间 / 完成时间信息卡、相关照片区、备注区、标记完成与编辑入口。
- 添加 / 编辑自定义事项页：封面图占位、事项名称、事项描述、分类、预计完成时间、重要程度、标签、是否公开到照片墙、保存按钮。
- 搜索页：搜索框、热门搜索标签、搜索结果列表。
- 照片墙页：全部 / 公开的 / 我的分段入口、照片网格、新增照片入口。
- 已完成列表页：顶部完成氛围区、统计分段、已完成事项列表。

## 字段与接口预留

- `category`: 当前 UI 使用标题推断分类展示，后续需要在 `AppCoupleTask` 中增加持久化分类字段。
- `description`: 事项描述当前作为 UI 占位文本展示，后续需要接入自定义描述保存。
- `plannedCompletedAt`: 预计完成时间入口已预留，当前模型暂无字段。
- `importance`: 星级重要程度入口已预留，当前仅为本地 UI 状态。
- `tags`: 标签管理入口已预留，当前模型暂无标签数组。
- `publicToPhotoWall`: 是否公开到照片墙入口已预留，当前不落库。
- `photoWallScope`: 照片墙“全部 / 公开的 / 我的”筛选入口已预留，当前为静态 UI。
- `sharePayload`: 详情页分享入口已预留，当前显示提示。
- `searchTagFilter`: 热门标签筛选入口已预留，当前显示提示。
